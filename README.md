# Error-Cancellation-and-the-Real-Drivers-of-Vehicle-Counting-for-Non-Invasive-Video-Traffic-Sensing
Vehicle counts from YOLOv8 can be right for the wrong reasons: false positives cancel misses. Tested on VisDrone and highway video: object size, occlusion and threshold drive failure, not crowd density. Density, flow and speed shift with detector settings.
